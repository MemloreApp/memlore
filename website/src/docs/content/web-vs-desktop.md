# Web vs desktop

Memlore Web is an optional companion to the desktop app. It opens a vault you already created on the desktop and synced to Google Drive. On the web you can read, search and write in your journal; your desktop app imports what you write on its next sync.

## Why some features stay on desktop

- **Zero-knowledge.** The web never sends your writing, passwords, or keys to a Memlore server, so features that would need one are left out.
- **No server.** Your journal travels only between your browser and Google Drive. A small Memlore sign-in service handles the Google token exchange and never sees your writing or keys, so there is nowhere to run AI, build an index, or send reminders.
- **Lazy reads.** The web fetches and decrypts entries on demand instead of holding the whole journal, so features that scan every entry stay on the desktop.
- **Deletion safety.** Deleting an entry on the web only moves it to the Trash on your desktop. Deleting forever and emptying the Trash from the web ask you to type DELETE first, a journal can be deleted from the web only once it is empty, and your desktop applies a web delete only to what is still as the web saw it: an entry restored or changed on your desktop since then is left alone. Anyone with your unlocked web session can still queue these, so lock or sign out before you leave a shared or borrowed computer.
- **Operating system only.** iCloud Drive, Touch ID, and reminders depend on the operating system and have no browser equivalent.
