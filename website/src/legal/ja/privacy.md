# プライバシーポリシー

Memlore はプライベートな日記です。このページでは、アプリとこのウェブサイトが情報をどう扱うか、そして決してしないことを説明します。

## 私たちについて

Memlore は [Anh-Thi Dinh](https://dinhanhthi.com) がつくっています。オープンソースの日記アプリです。お問い合わせ：[contact@memlore.app](mailto:contact@memlore.app)。

## 収集しないもの

Memlore のサーバーも、Memlore のアカウントもありません。アプリがあなたを監視することはありません。

- テレメトリーなし
- アナリティクスなし
- 広告なし
- トラッキングピクセルなし

## あなたのデバイス上の日記

日記はあなたのデバイス上の、暗号化されたローカルデータベースに保存されます。私たちには読めません。

## オプションのクラウド同期

同期は、あなたがオンにするまでオフのままです。保存先はひとつ選びます。あなたの Google Drive か iCloud Drive です。間に Memlore のサーバーはありません。

エントリー、メディア、設定は、アップロードされる前にデバイス上で暗号化されます。小さな同期リストとデバイス登録情報（ID、タイムスタンプ、削除フラグ、デバイス名。日記の本文は含みません）は JSON として保存され、他のデバイスが何を取得すべきかを把握できるようにします。

## オプションの Google Drive 同期

Google Drive を選んだ場合は、ご自身の Google アカウントを接続します。Memlore が求めるのは [drive.appdata](https://www.googleapis.com/auth/drive.appdata) スコープだけです。同期されたファイルは Google Drive の非表示のアプリケーションデータフォルダ（drive.google.com には表示されません）に置かれ、Memlore があなたの他の Drive ファイルを読むことはできません。

リフレッシュトークン、Google アカウントのメールアドレス、Drive のストレージ容量は、どのアカウントが接続されているかをアプリが表示できるよう、このデバイス上の暗号化されたデータベースにのみ保存されます。これらは接続を解除するまで保持され、解除するとローカルデータベースから削除されます。アクセストークンはメモリ上にのみ保持され、ディスクに書き込まれることはなく、アプリを閉じると消えます。

アプリで接続を解除しても、非表示のアプリケーションデータフォルダにすでにあるファイルは削除されません。Google 側のコピーを削除するには、Google Drive → 設定 → アプリの管理 → Memlore → ドライブから切断 を開いてください。

Google のユーザーデータは、あなたがオンにした Drive 同期を動かすためだけに使われます。Memlore の人間があなたの Google ユーザーデータを読むことはありません。データが届く Memlore のサーバーも存在しません。Memlore は次のことを行いません。

- データを販売すること、またはデータブローカーや情報再販業者に移転すること
- ターゲティング広告、パーソナライズ広告、興味・関心に基づく広告を含め、広告に利用すること
- 汎用的または非パーソナライズの AI や ML モデルの開発、改善、トレーニングに利用すること
- 信用力の判断、融資、その他アプリの機能に関係のない判断に利用すること
- あなた自身の Google アカウント内で Drive 同期を動かすために必要な場合、または法律で求められる場合を除き、第三者に移転すること

Google API から受け取った情報の Memlore による利用および他のアプリへの移転は、限定的使用の要件を含め、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy) に従います。

## オプションの iCloud Drive

iCloud Drive を選んだ場合（Mac の場合）、Memlore はあなたの iCloud Drive 内の Memlore フォルダに書き込みます。Finder ですでに見ているのと同じ iCloud Drive です。

Memlore があなたの代わりに Apple にサインインすることはなく、Apple のパスワードや iCloud のトークンを保存することもありません。この Mac ですでに使われている iCloud Drive のセッションを利用します。

上で説明したのと同じ暗号化済みのデータと JSON の同期リストが、このフォルダに保存されます。Apple があなたの日記を平文で受け取ることはありません。Apple の iCloud 利用規約が適用されます。

接続はアプリで解除できます。解除しても iCloud Drive 内の Memlore フォルダは削除されません。クラウド上のコピーを消したい場合は、そのフォルダをご自身で削除してください。

## オプションの AI

AI は、あなたがオプトインしてプライバシーに関する通知に同意するまでオフのままです。プロバイダーはあなたが選びます。ローカルまたはオンデバイス、あるいはホスト型のプロバイダーです。

ホスト型のプロバイダーを選んだ場合、送信したテキストはそのプロバイダーに届きます。Memlore はそれらのサービスを運営しておらず、その通信を見ることもありません。

## オプションの地図、場所、音声

地図、ジオコーディング、音声認識は、あなたがオンにした場合にのみ動作します。これらはあなたが選んだプロバイダーと通信します。たとえば Nominatim/OpenStreetMap、Mapbox、MapTiler、Apple MapKit、またはお使いの音声認識プロバイダーです。

## アプリのアップデート

アプリは、アップデートがあるときにお知らせできるよう、GitHub のリリース情報を取得することがあります。この確認はテレメトリーではありません。

## Memlore Web (web.memlore.app)

Memlore Web はオプションのブラウザ用コンパニオンです。既存の Memlore の日記をウェブブラウザから読むことができ、編集を有効にすれば、デスクトップアプリが取り込む編集を行うこともできます。

- **ブラウザにローカル保存されるもの：** Memlore Web がブラウザの IndexedDB に保存するのは、暗号化されたキャッシュだけです。マスター暗号鍵は WebAssembly のメモリ内にのみ厳密に保持され、金庫をロックするかタブを閉じた時点で消去されます。日記のエントリーは AES-256-GCM で暗号化された暗号文としてのみディスクに保存され、暗号化されていないテキストがブラウザのストレージに保存されることはありません。
- **Cloudflare Worker：** `web.memlore.app/api/*` にある一時的な Cloudflare Worker が、クライアントシークレットを保護するために、Google との OAuth 2.0 PKCE トークン交換を処理します。Worker があなたのマスター復旧フレーズ、暗号鍵、日記の内容を見たり、解析したり、記録したりすることはなく、トークンの永続的なデータベースやアクセスログも保持しません。
- **ホスティング基盤：** Memlore Web は Cloudflare Pages でホストされています。他のウェブサーバーと同様に、Cloudflare は DDoS 対策とコンテンツ配信のためだけに、標準的な HTTP リクエストヘッダーと IP アドレスを処理します。
- **Google Drive のスコープ：** Memlore Web は Google Drive の限定的な `drive.appdata` スコープ（非表示のアプリケーションデータ）にのみ接続します。あなたの個人的な Google Drive のドキュメント、写真、スプレッドシートを表示、閲覧、変更することはできません。
- **アナリティクスなし：** Memlore Web には、アナリティクスのトラッカー、広告スクリプト、トラッキング Cookie、行動テレメトリーは一切含まれていません。
- **すべてを削除する方法：** ウェブ上の痕跡はいつでもすべて削除できます。
  1. ブラウザの設定で、web.memlore.app のサイトデータを消去します。これにより、Memlore Web がそのブラウザに保存したもの（暗号化されたキャッシュ、未送信の編集、パスワードで保護された鍵）がすべて削除されます。Memlore Web の設定にある **Clear cache** ボタンで削除されるのは、キャッシュされた写真と動画だけです。
  2. Memlore のデスクトップアプリで、Settings → Security → Security actions → Connected devices を開き、ウェブのデバイスを削除します。
  3. [myaccount.google.com/permissions](https://myaccount.google.com/permissions) で Google Drive へのアクセス権を取り消します。

## このウェブサイト

この紹介用ウェブサイトは、アナリティクス用の Cookie を設定せず、日記のデータも収集しません。インタラクティブなデモはサンプルデータだけを使っています。

唯一の例外はダウンロードボタンで、ここは正確に説明しておく価値があります。ボタンは dl.memlore.app を経由し、ダウンロード数を数えたうえで、GitHub 上のファイルへ転送します。記録されるのは、日時、アプリのバージョン、そして Cloudflare が接続から推定した国です。IP アドレスは保存されず、Cookie も設定されません。これはアプリをダウンロードするときだけに行われ、アプリを使っている間に行われることはありません。アプリ自体は、今も、これからも、何も送信しません。
